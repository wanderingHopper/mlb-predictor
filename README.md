# Diamond Matchup — Editorial Light

A single-page, static MLB team matchup comparison site featuring Ryan's statistical scoring model.


## About this project

This is an independent, noncommercial student project.

Ryan developed the statistical scoring model to explore
comparisons between MLB teams using batting and pitching data.

Team statistics were sourced from Baseball-Reference.
The project is not affiliated with or endorsed by
Baseball-Reference, Sports Reference, or Major League Baseball.

The results compare relative team strength based on season statistics.
A higher percentage means a stronger rating under the selected weights,
not a predicted chance of winning an actual game.

## Site structure

- `index.html` — **the live homepage** at the root GitHub Pages URL; includes all layout and interaction code.
- `scores.js` — regenerated 2026 team scores from the supplied season CSVs.
- `features.js` — regenerated 2026 normalized per-stat data for optional custom weight experiments.
- `analytics-config.js` — GoatCounter site code, currently configured as `guyperson`.
- `build_scores.py` — reproducible Python script to regenerate `scores.js` (standard library only).
- `source/` — Ryan's original Jupyter notebook and **cleaned 2026** batting / pitching datasets. The notebook is retained for attribution and reference; the website uses data regenerated by `build_scores.py`.
- `.nojekyll` — keeps GitHub Pages serving the site as static files.

There are **no** `v1/`, `v2/`, or design-selection pages. This package is the complete V2-only repository content and should be extracted **directly into the repository root**, not into an extra subfolder.

## Publish on GitHub Pages

1. Push the files to the repository's default `main` branch.
2. In GitHub, open **Settings → Pages**.
3. Set **Source** = **Deploy from a branch**, **Branch** = `main`, **Folder** = `/(root)` and save.
4. The public site is at `https://YOUR_USERNAME.github.io/YOUR_REPOSITORY/` for an ordinary project repository.

## 2026 regular-season dataset

This snapshot uses the user-supplied **2026 MLB Hitting Statistics** CSV and Ryan-supplied `PITCHER.csv`. We removed the two presentation/title lines and the league summary rows; the 30 individual team rows and model-relevant values are otherwise preserved. The datasets have exactly matching team lists, 4,858 combined games, and 21,769 combined runs in each export. The pitching CSV itself does not contain a season label; confirm the source season with Ryan before treating it as independently verified.

The original notebook is kept for provenance and Ryan's model design; the 2026 website calculations are generated using the updated CSVs rather than by rerunning notebook outputs from an older data snapshot.

## Recalculate the model data

```powershell
python .\build_scores.py
```

The website requires no backend, build tooling, or paid hosting. It works with the **2026 regular-season** data snapshot in `scores.js` and `features.js`. The percentages shown are **relative normalized scoring shares**, not validated baseball win probabilities.

## Optional analytics: count completed comparisons

GitHub Pages has no shared server-side counter. This site supports [GoatCounter](https://www.goatcounter.com/) as an optional third-party analytics service. To enable it:

1. Create a GoatCounter account/site, ideally owned by Ryan.
2. Open `analytics-config.js` and set `window.GOATCOUNTER_SITE = "YOUR_SITE_CODE";` (the subdomain before `.goatcounter.com`).
3. Commit and push the file.
4. Visit the public site and click **Compare teams** with two different teams. In the GoatCounter dashboard, find the event **Completed matchup comparisons** (`compare-teams`).

The event is sent only after a valid explicit comparison; the initial automatic Yankees–Mets preview, changes to sliders, and Reset do not count. Repeated valid clicks count as repeated uses (not unique people). Page views are tracked separately. Counts are approximate because analytics can be blocked by browser settings or ad blockers. There is **no public counter** on the page. Analytics start only when configured and do not backfill past uses. Consider applicable privacy disclosures before enabling third-party analytics.

## Optional weight experiments

Expand **Adjust model weights (optional)** to change the offense/pitching blend, and **Fine-tune individual statistics** to edit all 18 original stat weights. The controls use the same min-max-normalized features as Ryan's original final notebook, and default values reproduce his exact original model.

Within each category, changed weights are divided by their sum to keep scores comparable; the defaults already sum to 1. The batting strikeout weight can be negative, as in the original model. If the custom weights produce invalid negative or zero scores, the site asks the user to adjust or reset them. Click **Compare teams** to apply. Custom settings are included in the copyable URL. These are exploratory experiments, not validated improvements to the predictor.
